# 消污除腐 - 人脸识别预警系统

一个基于实时人脸识别的预警系统，用于检测特定人员的出现。

## 功能特点

- 📹 实时摄像头监控
- 🎯 基于DeepFace的高精度人脸识别
- ⚡ 快速预警响应
- 🎨 现代化的设置界面
- 💾 配置持久化存储
- 🔔 全屏警报提示（显示人员照片、姓名、匹配度）
- 👤 支持人员名称管理
- 📷 摄像头快照保存
- ✖ 手动取消警报

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
python main.py
```

## 技术栈

- **OpenCV**: 摄像头采集和人脸检测
- **DeepFace**: 高精度人脸识别
- **PyWebView**: 现代化UI界面
- **Python**: 核心逻辑实现

## 配置说明

首次运行会打开设置窗口，您可以：
- 添加需要识别的人脸照片
- 调整识别灵敏度
- 预览摄像头画面
- 配置警报参数

设置会自动保存，下次启动时恢复。
